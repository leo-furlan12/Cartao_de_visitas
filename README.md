## 💻 Sobre o Projeto

Este projeto nasceu com o objetivo de centralizar minhas informações profissionais, habilidades técnicas e projetos pessoais. Como estudante de **Ciência da Computação na UTFPR**, busquei criar uma interface que refletisse a minha paixão por tecnologia: limpa, direta e com elementos que remetem ao ecossistema de desenvolvimento, como a seção "Sobre Mim" estilizada como um terminal de comandos Linux.

## ✨ Principais Funcionalidades (Features)

- **🎨 Design Moderno:** Uso de paleta *Dark Mode* com pontos de luz (Glow/Neon) para destacar botões e elementos interativos.
- **📱 100% Responsivo:** O layout se adapta perfeitamente a monitores Ultrawide, Notebooks, Tablets e Smartphones (via Media Queries).
- **🖥️ UI de Terminal:** Seção "Sobre Mim" simulando a interface de um terminal Linux puro feito com CSS e animação de cursor piscante.
- **⚡ Navegação Fluida:** Scroll suave (Smooth Scroll) ao clicar nos itens do menu fixo (Sticky Header).
- **🗂️ Cards Interativos:** Grade de habilidades (Grid System) e contatos com efeitos de elevação e brilho ao passar o mouse (Hover effects).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído "na unha", focando nos fundamentos da web para garantir a máxima performance e controle sobre os estilos:

* **HTML5:** Semântica e estruturação lógica de blocos.
* **CSS3:** * `Flexbox` e `CSS Grid` para alinhamentos complexos.
  * `Backdrop-filter` para o efeito de vidro fosco (Glassmorphism).
  * `Keyframes` para animações fluidas.
  * `@media queries` para responsividade (Mobile-friendly).
* **Fontes:** Google Fonts (Archivo Black, Quicksand, JetBrains Mono).
* **Hospedagem:** GitHub Pages (CI/CD nativo).
